Instrucciones de Uso

1. Activa el modo magia con un DOBLE TOQUE en cualquier parte del visor superior.
2. Un minúsculo punto en la esquina superior izquierda indica que la calculadora está lista para el efecto.
3. Al escribir cualquier número después de un operador (+, -, ×, ÷), la calculadora escribirá automáticamente los dígitos necesarios para llegar exactamente al resultado final configurado.
4. Si pulsas igual (=) antes de completar el número, realizará una cuenta real para no levantar sospechas.
5. El botón AC limpia la pantalla y desactiva el modo magia automáticamente.
6. Borrar dígitos uno a uno (⌫) mantiene el modo magia activo.
7. Pulsa la tecla igual (=) 3 veces rápidamente para cerrar la aplicación en caso de emergencia.
